Versand & Integrationen

E-Mail-Versand (Massenmail)

Direktversand der Rundmails über Google Apps Script – verschickt aus eurem Vereins-Google-Konto. Einmalig einrichten (Anleitung unten), dann kannst du im Tab „Massenmail" direkt senden.

So richtest du den Versand ein (einmalig)
  1. Mit dem Vereins-Google-Konto auf script.google.com → „Neues Projekt".
  2. Den Code unten komplett einfügen (vorhandenes ersetzen) und speichern.
  3. „Bereitstellen" → „Neue Bereitstellung" → Typ Web-App, Ausführen als Ich, Zugriff Jeder → Bereitstellen, Berechtigungen erlauben.
  4. Die Web-App-URL (endet auf /exec) oben einfügen und „Verbindung testen".

Verschickt wird über das Google-Konto, mit dem du das Skript erstellst. Die „Absender-Adresse" wird als Antwort-Adresse gesetzt (und als Absender, falls sie ein verifizierter Alias dieses Kontos ist).

function doPost(e){
  var d = JSON.parse(e.postData.contents);
  if (d.action === 'test'){ return out({ ok:true }); }
  if (d.action === 'mail'){
    var to = d.from || Session.getEffectiveUser().getEmail();
    var opts = { bcc:(d.bcc||[]).join(','), name: d.fromName || 'ELKI Verein Trimmis', replyTo: d.from || '' };
    try { if (d.from) opts.from = d.from; GmailApp.sendEmail(to, d.subject || '(kein Betreff)', d.body || '', opts); }
    catch (err){ delete opts.from; GmailApp.sendEmail(to, d.subject || '(kein Betreff)', d.body || '', opts); }
    return out({ ok:true, sent:(d.bcc||[]).length });
  }
  return out({ ok:false });
}
function out(o){ return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }

Wichtig: Für den Anmelde-Prozess (Vertrag als Anhang) braucht es die erweiterte Fassung des Skripts – sie steht in den Einstellungen unter „Anmelde-Prozess“. Die Fassung hier oben kann keine Anhänge verschicken.

Wartung / Update

Geführter Ablauf für ein Update: Ankündigung setzen, Datenstand sichern – und zum gewählten Zeitpunkt sperrt sich das Tool nahtlos selbst für alle, damit während des Updates niemand mehr etwas ändert.

1 Ankündigung

Wann findet das Update statt? Ab dem „Live schalten“ sehen alle einen Hinweis mit diesem Zeitpunkt.

2 Automatische Sperre

Zum oben gewählten Zeitpunkt geht die Ankündigung nahtlos in eine Vollbild-Sperre über – ohne Lücke. Ab dann kann niemand mehr etwas ändern, der Datenstand bleibt sicher.

3 Datenstand sichern

Lade jetzt ein Komplett-Backup herunter, bevor das Update läuft – zur Sicherheit.

4 Zusammenfassung & Live schalten

Mit „Live schalten“ erscheint sofort die Ankündigung. Zum gewählten Zeitpunkt sperrt sich das Tool automatisch. Die Sperre beendest du nach dem Update selbst.

1 Wie sollen die Mails rausgehen?

Wird geprüft …
  1. script.google.com öffnen — mit dem Vereins-Google-Konto — und auf Neues Projekt klicken
  2. Den vorhandenen Beispielcode ganz löschen, unseren einfügen (Knopf unten), dann Strg + S
  3. Oben rechts Bereitstellen → Neue Bereitstellung → Zahnrad → Typ Web-App
  4. Ausführen als Ich, Zugriff Jeder → Bereitstellen → Zugriff erlauben (Google fragt nach Berechtigungen — das musst du selbst bestätigen)
  5. Die angezeigte Web-App-URL (endet auf /exec) kopieren und unten einfügen
function doPost(e){
  var API_SECRET = PropertiesService.getScriptProperties().getProperty('API_SECRET');
  var d = JSON.parse(e.postData.contents);
  if (API_SECRET && d.token !== API_SECRET) return out({ ok:false, error:'token' });
  if (d.action === 'test'){ return out({ ok:true }); }
  if (d.action === 'mail'){
    var to = d.to || d.from || Session.getEffectiveUser().getEmail();
    var opts = { name: d.fromName || 'ELKI Verein Trimmis', replyTo: d.from || '' };
    if (d.bcc && d.bcc.length) opts.bcc = d.bcc.join(',');
    if (d.attachments && d.attachments.length){
      opts.attachments = d.attachments.map(function(a){
        return Utilities.newBlob(Utilities.base64Decode(a.data), a.mimeType || 'application/pdf', a.name || 'Vertrag.pdf');
      });
    }
    try { if (d.from) opts.from = d.from; GmailApp.sendEmail(to, d.subject || '(kein Betreff)', d.body || '', opts); }
    catch (err){ delete opts.from; GmailApp.sendEmail(to, d.subject || '(kein Betreff)', d.body || '', opts); }
    return out({ ok:true, sent: (d.bcc && d.bcc.length) ? d.bcc.length : 1 });
  }
  return out({ ok:false });
}
function out(o){ return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
Ein Zugriffs-Token ist nicht nötig, damit es läuft. Wer es sicherer will, legt später unter Projekteinstellungen → Skripteigenschaften ein API_SECRET an und trägt denselben Wert unter „Versand & Integrationen“ ein.

Änderst du den Code später: immer Bereitstellen → Bereitstellungen verwalten → Stift → Neue Version. Sonst läuft weiter die alte Fassung.
Was das bewirkt: Das Gmail-Fenster öffnet sich gezielt in diesem Konto (über authuser), auch wenn im Browser mehrere Google-Konten angemeldet sind.

Was es nicht bewirkt: Gmail verschickt immer aus dem Konto, in dem du angemeldet bist — ein fremder Absender lässt sich nicht erzwingen. Ist das Vereinskonto im Browser nicht angemeldet, fragt Gmail zuerst danach.

Leer lassen = das gerade aktive Konto.
2 Welches Dokument bekommen die Eltern?
  1. Vertrags-PDF ins Google Drive des Vereins legen
  2. Rechtsklick auf die Datei → Freigeben
  3. Unter „Allgemeiner Zugriff“ von „Eingeschränkt“ auf „Jeder, der über den Link verfügt“ stellen
  4. Link kopieren und hier einfügen
Für später – Vertrag austauschen ohne neuen Link:
In Drive Rechtsklick auf die Datei → Dateiversionen verwalten → Neue Version hochladen. Der Link bleibt derselbe, du musst hier nichts ändern. Nur wenn du eine ganz neue Datei anlegst, brauchst du einen neuen Link.

Das PDF ist ein leeres Formular – es enthält keine Personendaten. Lade dort keine ausgefüllten Verträge hoch.

Wird geladen …

Ein PDF für alle Angebote. Höchstens 4 MB. Ein Gmail-Fenster kann keine Datei anhängen – beim empfohlenen Weg zählt deshalb der Link oben, nicht diese Datei.

Daten

Daten Import/Export

Dokumente am Kind

PDF- und Bild-Dateien (PNG/JPG) werden pro Kind direkt in der Datenbank (Firestore) gespeichert – keine zusätzliche Firebase-Einrichtung nötig, es funktioniert sofort. Die Dokumente bleiben über alle Schuljahre erhalten.

Max. 10 MB pro Datei. Grosse Dateien werden automatisch in Teile zerlegt. Hochladen/Löschen erfolgt im Kind-Formular (Bereich „Dokumente"); ein Klick auf den Dateinamen öffnet das Dokument.

Datensicherung (Backup)

Lädt den gesamten Datenstand als einzelne Sicherungsdatei herunter – Kinder, Buchungen, Schuljahre, Kapazitäten, Tickets, Anwesenheit, Erinnerungen, Infoseite, hochgeladene Dokumente und Einstellungen. Bewahre die Datei sicher auf. Geht etwas verloren, kannst du damit den ganzen Stand wiederherstellen.

Format .json – das bewährte Komplett-Backup. Inklusive der hochgeladenen Dokumente (PDF/Bilder). Login-Passwörter sind nicht enthalten (die verwaltet Firebase separat). Wiederherstellen überschreibt den aktuellen Stand vollständig.

Automatisch in einen Ordner auf diesem PC

Einmal einen Ordner wählen – danach legt die App die Sicherung dort ab, ohne Speichern-Dialog. Ist die letzte Sicherung älter als die eingestellte Anzahl Tage, erinnert die App nach dem Anmelden daran.

Kinderdaten: Die Sicherungen enthalten personenbezogene Daten. Ein Ordner in OneDrive bedeutet, dass sie in die Cloud synchronisiert werden – wähle bewusst.
Aufräumen: Übersteigt die Anzahl den Wert unter „Behalten", löscht die App die ältesten – ausschliesslich eigene Dateien nach dem Muster elki-backup-*.json in diesem Ordner. Andere Dateien bleiben unberührt. Wähle „alle", wenn nichts gelöscht werden soll.
Browser: Chrome und Edge; in Firefox und Safari bleibt es beim normalen Herunterladen.
